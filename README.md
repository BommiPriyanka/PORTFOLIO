# Bommi Priyanka Portfolio

Premium light-theme React portfolio generated from Bommi Priyanka's resume.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Add your profile image

Place your photograph at:

`public/images/profile.png`

The portfolio already contains a fallback placeholder if the image is missing.

## Main stack

- React
- Vite
- Framer Motion
- Lucide React
- CSS

## Notes

- LinkedIn, GitHub and LeetCode links are already configured.
- The contact form is intentionally visual-only; no backend service was invented.
- Project GitHub buttons currently point to the supplied GitHub profile because individual repository URLs were not provided.
